🏥 Hospital Management System

A full-stack Hospital Management System built using Spring Boot (Backend) and Angular (Frontend) to manage patients, doctors, appointments, billing, and hospital operations efficiently.

🚀 Features

👨‍⚕️ Doctor Management (Add, Update, Delete, View)

🧑‍🤝‍🧑 Patient Management

📅 Appointment Scheduling

💳 Billing & Payment Management

🔐 Secure Authentication & Authorization (JWT Based)

🏥 Role-Based Access Control (Admin / Doctor / Staff)

📊 Dashboard with real-time data

📡 RESTful APIs with proper validation & exception handling

🛠️ Tech Stack
Backend

Java 17+

Spring Boot

Spring Security (JWT Authentication)

Spring Data JPA

Hibernate

MySQL / PostgreSQL

Maven

Frontend

Angular 17+

TypeScript

HTML, CSS, Bootstrap

Tools

Git & GitLab

Postman

IntelliJ IDEA

Jenkins (CI/CD)

🔐 Security

JWT-based Stateless Authentication

Role-Based Authorization

CSRF Protection

Password Encryption using BCrypt

Global Exception Handling

📦 Project Architecture

Layered Architecture (Controller → Service → Repository)

DTO Pattern

Exception Handling using @ControllerAdvice

Microservice-ready structure

REST API standards followed

⚙️ Installation & Setup
Backend
git clone <repository-url>
cd hospital-management-system
mvn clean install
mvn spring-boot:run

Application runs on:

http://localhost:8080
Frontend
cd hospital-frontend
npm install
ng serve

Application runs on:

http://localhost:4200
